Esta pasta não tem relação com o app Constância, que ocupa o resto do repositório. São
documentos, não código.

## Sobre as fontes

Os percentuais e faixas de preço são estimativas do mercado brasileiro, reunidas para
dar ordem de grandeza. Não vieram de nenhuma fonte primária verificada nesta sessão, e
servem para dimensionar esforço, não para prever resultado.

Este material também não descreve o negócio de nenhuma pessoa específica. As duas
páginas usadas como referência inicial ficaram inacessíveis pelo bloqueio de rede do
ambiente, então nada aqui foi extraído delas.
